# TeachTrack 用户需求基线

需求来源：`docs/prompts/00-product-requirements.prompt.md` 至 `09-quality.prompt.md`。

## P0

- UR-001 学生档案、状态、搜索、筛选、归档和 Student Workspace。
- UR-002 课程记录、快速续课、知识点关联和学生 Timeline。
- UR-003 考试与学生成绩分离，支持得分率、趋势、失分和知识点关联。
- UR-004 知识点树、学生掌握等级 0–4 和历史事件。
- UR-005 作业、问题记录、家校沟通、下一节课计划、周/月/学期计划和 Task。
- UR-006 Dashboard、日历、教师/学生统计和空状态/错误状态。
- UR-007 JSON 本地备份恢复、恢复前预览/确认和 CSV 成绩导出。
- UR-008 Room、显式迁移、Flow/Repository、合理索引和性能测试。
- UR-009 Android 手机/平板响应式布局、绿色质感主题、可访问性和数据隐私。

## P1/P2 边界

- P1：模板、附件、批量操作、增强分析和更多导出。
- P2：可选 AI、云同步和多设备同步；不得成为 P0 正常使用前提。

## 非目标

不开发招生 CRM、财务、机构排课、工资、商城、直播、在线课堂、学生端或家长端 App。
