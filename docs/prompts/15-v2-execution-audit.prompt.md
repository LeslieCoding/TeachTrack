# TeachTrack 2.0 Prompt 15 — 执行、审计与撤销

实现 Copilot 命令执行闭环。

流程：

`输入 -> 解释 -> 预览/澄清 -> 用户确认 -> 校验 -> 执行 -> 结果 -> 撤销窗口/历史`

要求：

- 每次执行显示影响的学生、模块、字段和数量。
- 审计记录保存本地但默认脱敏，不保存 API Key 和完整敏感上下文。
- 可逆创建/编辑提供 Undo；永久删除、自动发送消息在 2.0 alpha 禁止自动执行。
- 失败要说明失败阶段，并保留用户原始草稿。
- 支持清理 Copilot 历史。

验收：确认前无写入；成功后可看到记录；可逆操作可撤销；失败和取消不损坏既有数据。
