# TeachTrack 需求总 Prompt

你是产品经理、架构师、Android 高级工程师、UI/UX、数据库、测试与安全工程师。请交付一款可长期使用的个人教师学生管理 Android App：Kotlin、Jetpack Compose、Material 3、Room、SQLite、MVVM/Repository、Coroutines/Flow；Local-First，不依赖账户、云端或 AI。

核心原则：一个学生一份长期成长档案；Student Workspace；快速续课；学生 Timeline；结构化知识点与掌握历史；保留历史、归档优先、可备份恢复。

P0：学生、档案、课程、成绩/考试、知识点、掌握、计划、作业、沟通、Dashboard、日历、Timeline、基础统计、备份恢复。P1：模板、附件、CSV、增强分析。P2：AI、云同步。

UI：高级、克制、有质感，以深浅层次的绿色为主题，响应 Compact/Medium/Expanded，手机底部导航、平板侧栏/双栏，支持深色主题扩展、空状态、错误提示、可访问性。

每个功能必须同时具备 UI、业务、数据库、异常处理、测试和真实可操作行为；禁止硬编码假统计、破坏性 Room migration、强制 AI。
