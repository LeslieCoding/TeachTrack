# 题库后续开发路线

- 日期：2026-11-06
- 当前运行环境：Cloudflare Workers + D1（亚太区）
- 生产入口：`https://teachtrack.leslieholmes.ccwu.cc`
- 当前数据：30 学生、31 课堂、177 知识点、1 道题

## 结论

题库后端能力已经齐全，当前主要缺口是 **录题入口** 和 **题目数量**，不是数据库结构。下一阶段先完成 App 录题、编辑与批量导入，再考虑图片附件和 AI 生成。

## 现状

### 后端已具备

- 题目新增、修改、软删除
- 版本历史与乐观锁（旧版本返回 409）
- 草稿、待审核、待教师审核、已审核、已拒绝状态
- 题干精确去重、规范化去重、近似相似题
- 选项、标准答案、解析、得分点、解题步骤
- 多知识点关联和重要度
- 附件关联接口
- 按学科、年级、题型、难度、知识点、来源、审核状态、关键词搜索
- 试卷导入、逐题分析、审核入题库
- 从已审核题库组卷、提交、掌握度更新

### Android 当前只有

- 题库列表与搜索
- 题目详情
- 通过 / 拒绝审核
- 试卷分析页面
- 精准练习页面

### 当前缺口

1. App 不能新增或编辑题目
2. App 不能批量导入题目
3. App 没有完整筛选栏、批量审核、批量软删除
4. 知识点没有树形管理、合并和归类界面
5. 图片、电路图、实验装置图无法上传（R2 尚未开通）
6. AI 题目生成与质量门未接真实 Provider

## 开发顺序

### P1 录题与编辑

目标：教师可以在平板或手机上完整录一道题。

范围：

- 学科、年级、教材版本
- 题型、难度、来源
- 题干、选项、标准答案、解析
- 知识点多选
- 保存草稿、提交审核
- 录入前调用 `/api/v1/questions/duplicates`，重复题干给出提醒
- 编辑时携带 `baseVersion`，409 冲突时提示刷新

验收：

- 在 OPPO Pad 完整录入一道选择题和一道计算题
- 保存草稿后可在列表看到
- 提交审核后可被通过
- 重复题干无法静默保存
- 两处同时修改同一道题时，后提交方收到版本冲突

### P2 批量导入

目标：一次导入几十到几百道题。

推荐格式顺序：

1. 粘贴文本：按空行或题号切分，先预览再入库
2. DOCX：提取题干、选项、答案、解析
3. CSV：教师可控字段映射
4. 试卷分析结果直接批量入库

每条预览记录必须显示：

- 切分后的题干
- 识别出的题型和难度
- 匹配到的知识点
- 重复检测结果
- 错误原因

验收：

- 一次导入 50 道题
- 重复执行同一批导入不产生重复题
- 无法识别的条目进入错误列表，不静默丢弃
- 导入后可批量审核

### P3 题库管理

范围：

- 学科、年级、题型、难度、审核状态、知识点筛选
- 批量审核、批量软删除、恢复
- 题目总数、待审核数、各知识点题量
- 最近修改与版本历史

验收：

- 从 500 道题中筛出“初三 + 电功率 + 难度 3 + 待审核”
- 批量通过 20 道题
- 软删除后列表隐藏，数据仍可恢复

### P4 图片与扫描件

前置条件：Cloudflare R2 开通，或切换到其他 S3 兼容存储。

范围：

- 拍照/相册选择
- 裁剪旋转
- 私有上传、签名下载
- 题干图、选项图、解析图
- 原试卷 PDF 与页面截图关联

在此之前只录入纯文字题，不把图片塞进 D1。

### P5 AI 生成与变式

前置条件：题库已有至少 300 道教师审核题，避免 AI 从空库生成噪声。

范围：

- Provider 抽象：OpenAI / Kimi / Claude / 本地模型
- 变式题优先基于历史错题
- AI 原创必须进入 `NEEDS_TEACHER_REVIEW`
- 自动检查题干完整性、答案唯一性、单位、难度、知识点匹配
- 与已有题做三级去重
- 教师确认后才能进入 `APPROVED`

验收：

- 生成 10 道变式题，至少 8 道通过教师审核
- 重复题不会进入题库
- AI 写操作全部有审计记录

## 第一批内容目标

- 学科：先限定初中科学
- 题量：300 道已审核题
- 覆盖：八年级上、八年级下、九年级上主要章节
- 每题至少 1 个知识点
- 重复题率低于 1%
- 用这 300 道题生成 1 份练习，在 App 完成提交和掌握度更新

## 推荐立即开始

P1 录题与编辑 + P2 文本批量导入。

这两项完成后，题库才具备持续积累内容的能力；AI 和图片功能都排在其后。
