## 三、内容级抽样结果

定向抽样 68 个 docx（初三/初二/初一/期中备考/电学/易错点等 10 个代表性目录，全部解析成功）+ 30 个 docx 图片内嵌检查：

| 标记 | 命中 | 占比 | 对应 schema |
|------|------|------|------------|
| 选择题（A./B./C./D. 选项） | 64 | 94% | SINGLE_CHOICE 是绝对主力 |
| 引用图（如图/右图/所示） | 64 | 94% | 题干依赖图片 |
| 含参考答案区 | 24 | 35% | 与原卷/解析分文件一致（原卷版无答案） |
| 填空（下划线空） | 23 | 33% | FILL_BLANK |
| 实验探究字样 | 14 | 20% | EXPERIMENT |
| 含解析区 | 12+5 | 25% | 解析版文件才有 |
| 显式"计算题"字样 | 3 | 4% | CALCULATION 很少自我标注，需按内容判断 |
| **内嵌图片（word/media）** | **30/30** | **100%** | 中位数 37 张/文档 |

真题来源可程序化提取：题干尾部普遍带 `（2023七年级上·浙江台州·期末）` 式标注，抽样中命中的主要来源：杭州/期中、浙江一模、中考真题、宁波期末/期中、金华阶段练习、嘉兴一模、绍兴阶段练习等——即**浙江各市统考真题 + 浙江专版模拟**。

结论：
1. **纯文本导入会丢掉题干的核心信息**（94% 题引图、100% 文档含内嵌图）。P2 文本导入上线时，必须给"含图题"打标记并挂占位附件，P4（R2 图片）不能再视为可选项，而是题库可用性的前提。
2. 答案/解析不能指望单文件，"原卷版/解析版"配对是数据完整性的关键。
3. 题型自动判定可行：选择题按选项标记、填空按空位、实验探究按字样；计算题需按"数值+单位求值"内容特征识别。

## 四、对 P2 批量导入的直接建议

1. **优先导入顺序**：初三中考专题（讲练测/易错/真题，量最大、与考情分析直接对应）→ 初二电学（学生分化重灾区）→ 初一知识点+题型（结构化最好，适合跑通流程）。
2. **第一批 300 道达标路径**：从"知识点+题型"类（48+2 篇，每篇 20-50 题）+ 易错点类（92 篇）抽取即可轻松超过 300 道，且自带知识点标签。
3. **解析器要点**（按本扫描发现）：
   - 章节号、教材版本、学年从文件名正则提取，不要从正文猜。
   - "原卷版/解析版"双文件配对：以解析版为准提取答案+解析，题干以原卷版为准。
   - 真题题干内含来源标注 `（2023七年级上·浙江台州·期末）`，可正则提取为 source_name + 年份。
   - 题型判断看正文标记：`（　　）`+A./B./C./D. 选项 = SINGLE_CHOICE；`____` 填空 = FILL_BLANK；"实验探究"= EXPERIMENT；"计算题/=数值+单位"= CALCULATION。
   - 图片题占比极高（94% 题干引图、100% 文档含内嵌图，见第三节），导入时必须标记含图题，等 P4 R2 开通后补图。
4. **版权口径**：商用系列一律 `copyright_status=PERSONAL_USE, usage_scope=PRIVATE_TEACHING`；不对外分发。
