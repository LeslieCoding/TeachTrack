## 解析与去重规则

1. 文件按 SHA-256 去重；完全相同内容只解析一次。
2. DOCX 读取 `word/document.xml`，保留段落的 Word 自动编号 `numPr`，因此看不到“1.”文本的题库也能正确切题。
3. 原卷与解析版按规范化题干合并，答案、解析取更完整的一方。
4. 只有题号答案的“参考答案”按同目录题号表合并，不把答案表当题目。
5. 规范化题干与后端保持一致：只剥离开头题号，去标点/空白但保留题干内数字，再计算 SHA-256；数据库唯一索引阻止重复。
6. 无选项、无答案、无解析且没有任何提问特征的讲义片段会剔除。

## 格式覆盖

- DOCX：直接解析正文、表格段落、自动编号和内嵌图片计数。
- DOC：antiword 失败时用本机 Microsoft Word COM 只读提取。
- PDF：128 个有文本层可解析；79 个为纯图片扫描件，未做 OCR。
- ZIP：185 个压缩包及其中 452 个条目、63 个嵌套 ZIP 递归处理，内存中读取，不落临时文件。
