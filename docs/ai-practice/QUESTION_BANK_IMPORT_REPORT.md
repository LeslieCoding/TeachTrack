## 解析与去重规则

1. 文件按 SHA-256 去重；完全相同内容只解析一次。
2. DOCX 读取 `word/document.xml`，保留段落的 Word 自动编号 `numPr`，因此看不到“1.”文本的题库也能正确切题。
3. 原卷与解析版按规范化题干合并，答案、解析取更完整的一方。
4. 只有题号答案的“参考答案”按同目录题号表合并，不把答案表当题目。
5. 规范化题干与后端保持一致：去标点/空白、数字统一替换，再计算 SHA-256；数据库唯一索引阻止重复。
6. 无选项、无答案、无解析且没有任何提问特征的讲义片段会剔除。

## 格式覆盖

- DOCX：直接解析正文、表格段落、自动编号和内嵌图片计数。
- DOC：antiword 失败时用本机 Microsoft Word COM 只读提取。
- PDF：128 个有文本层可解析；79 个为纯图片扫描件，未做 OCR。
- ZIP：185 个压缩包及其中 452 个条目、63 个嵌套 ZIP 递归处理，内存中读取，不落临时文件。

## 已知限制

- 79 个纯扫描 PDF 没有 OCR，因此其中的题目未入库；这些文件已记录为无题目来源，不伪造内容。
- 41,802 道含图题的图片文件尚未上传，题目标记为“含图待补”；文字题干、选项、答案和解析已尽量保留。
- 复杂表格、公式、多小问的版式会被文本化，个别题干的换行和表格顺序可能不完美。
- 自动识别有误的题会进入待审核；49 道题干混入解析标记、354 道题干超过 5000 字，均强制标为待审核。
- 建议先抽查九年级、八年级和实验探究题。
- 数学、语文、英语等非科学资料归入“其他”，没有混入初中科学。

## 复跑

```powershell
# 仅解析到本机状态库，不写正式服务
python scripts/import_question_bank.py --parse-only

# 从已有状态继续导入
python scripts/import_question_bank.py --import-only --import
```

中间分片状态库在导入完成后已清理；重新运行脚本会在 `backend/data/import/` 重建忽略于 Git 的状态库和报告。
